# UniFilter AI

## プロジェクト概要
大学のGmailに届く大量のシステム通知（manabaの更新、paizaのスカウトなど）によって、教員や事務局からの「本当に重要な連絡」が埋もれてしまう課題（バグ）を解決するWebアプリケーションです。
AIが送信元と文脈を解析し、重要メールのハイライトと、システム通知の自動振り分け・ダイジェスト化を行います。

## Antigravity（AI）へのプロンプト
以下のプロンプトをAntigravityのAIアシスタントに入力して、プロトタイプを作成します。

---
あなたは優秀なフルスタックエンジニアです。大学生向けのGmail特化型フィルタリングアプリ「UniFilter AI」のプロトタイプ（Web画面のモックアップ）を作成してください。

【要件】
・目的：manabaや就活サイトからの大量の自動通知を裏側に隠し、教員や大学事務からの「人間が送った重要なメール」だけを最上部にハイライト表示するダッシュボード。
・画面構成：
　1. 左側：サイドバー（受信トレイ、重要メール、自動通知フォルダの設定など）
　2. 中央：メール一覧（重要メールが目立つように視覚的に区別されていること）
　3. 右側：AIによる「本日の未読メール要約ダイジェスト」パネル
・デザイン：学生が毎日開きたくなるような、シンプルでモダンなダークテーマのUI。

まずは動作イメージが伝わるように、HTML, CSS, JavaScriptを1つのファイル（index.html）にまとめたフロントエンドのコードを出力してください。ダミーのメールデータ（大学からの連絡やmanabaの通知など）をJSの配列で用意し、画面に描画するようにしてください。
