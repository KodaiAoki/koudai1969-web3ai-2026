# 第5回課題 — プロトタイプ v1

## プロダクト概要

**UniFilter AI** — 大学生向け AI メールフィルタリングダッシュボード

## 解決するバグ（バグリストより）

> **バグ #1：大学メールの埋没**
> manabaや就活サイトの自動通知が多すぎて、教員からの重要なメールを見逃しそうになる。

## 誰のためのプロダクト？

大学の Gmail に毎日大量の自動通知が届き、教員や事務局からの重要な連絡が埋もれてしまう **大学生** のために作りました。

## 何が動くか（プロトタイプ v1 の機能）

- ✅ **AI フィルター済み受信トレイ**: 教員・大学事務のメール（重要）と manaba/paiza の自動通知（システム）を視覚的に分離表示
- ✅ **今日のダイジェストパネル**: 統計・要対応アクション・AI 要約・通知内訳をワンビューで確認
- ✅ **インタラクティブなサイドバー**: 「重要メール」「自動通知」「期限あり」でフィルタリング
- ✅ **検索機能**: 送信者・件名・本文プレビューでリアルタイム絞り込み
- ✅ **AI フィルター設定パネル**: 各フィルターのオン/オフ切り替え
- ✅ ダミーデータ（manaba × 4、paiza × 2、教員 × 2、事務局 × 1）で実際の使用感を再現

## 技術スタック

- HTML / CSS / JavaScript（単一ファイル `index.html`）
- フレームワーク不使用・ビルドツール不使用
- ダークテーマ UI
