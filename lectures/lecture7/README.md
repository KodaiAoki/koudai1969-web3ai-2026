# 第7回課題 — プロトタイプ v3

## プロダクト概要

**UniFilter AI v3** — 大学生向け AI メールフィルタリングダッシュボード（実データ対応版）

## v2 → v3 の最大の差分

**「全部サンプルデータ」問題を解消。ユーザーが自分の本物のメール（テキスト貼り付け / JSON / CSV）を取り込むと、AI が自動分類・要約・返信ドラフトを生成し、実データが画面上で動く状態になった。**

## 新機能詳細

### 1. メールインポート機能（v3 最重要差分）

| 入力方式 | 操作 |
|----------|------|
| テキスト貼り付け | メールをそのままコピペ。`From:` / `Subject:` / `Date:` ヘッダーを自動解析 |
| JSON | 配列形式で複数件を一括取り込み、またはファイルアップロード |
| CSV | `from,subject,date,body` の列形式、またはファイルアップロード |

### 2. AI 自動解析（取り込み後 1.4 秒で完了）
- **自動分類**：送信者のドメイン・キーワードから「重要」「自動通知」を判別
- **AI 要約生成**：期限・返信要否を抽出してサマリを自動生成
- **返信ドラフト生成**：先生・教員を自動判別し敬称を使い分けたドラフトを作成

### 3. 実データ / サンプルの視覚的区別
- 取り込んだメールには **✦ 実データ** バッジを表示
- サンプルデータは **サンプル** ラベルで区別
- サイドバーの「サンプルを非表示」で実データのみ表示に切り替え可能

### 4. その他 UI 改善
- インポートボタンをトップバーに常設（キーボードショートカット `I` も追加）
- 取り込み件数をサイドバーにリアルタイム表示
- ダイジェストパネルの統計・アクションアイテムが実データに基づいて動的更新

## v2 からの継続機能

| 機能 | 状態 |
|------|------|
| メール詳細パネル | ✅ 維持 |
| AI 返信ドラフト | ✅ 維持・実データにも対応 |
