# 第8回課題 — プロトタイプ v4（価値検証フェーズ）

## プロダクト概要

**UniFilter AI v4** — 大学生向け AI メールフィルタリングダッシュボード（継続利用対応版）

## v3 → v4 の差分（1行）

**取り込んだメールから AI が「今日やるべきタスク／締切」を優先度順に自動抽出してチェックリスト化し、その状態をブラウザに保存。再訪時に前回の続きから使える「毎日開きたくなる」体験を追加した。**

## なぜこの機能か（価値検証の狙い）

v3で「本物のデータが動く」状態は達成した。v4では **"一度試す" から "また使いたくなる"** への転換を狙い、**継続利用の動機**を1点突破で作ることに集中した。

- **AI ToDo 抽出 × 永続化** は相互に依存する：保存がなければ ToDo の進捗は毎回消え、達成感も継続前提も生まれない。この2つをセットで最小実装した。
- 「今日やること」をチェックして消していく達成感 ＋ 再訪時に前回の状態が残る安心感が、**毎日開く理由**になる。

## 新機能詳細

### 1. AI ToDo 自動抽出（v4 最重要差分）
- インポート済み／サンプルのメールから **「要返信」「締切あり」** を検出し、対応すべきタスクを自動生成
- **優先度を自動付与**：締切あり＝高 / 要返信＝中、優先度順に並べて提示
- 本文・要約から **締切（例：明日12:00、6/5 まで）を自動抽出**してタスクに表示
- チェックで完了 → **進捗バー（残り◯件 / X/Y）** が動き、全完了で「🎉 今日のタスク完了！」
- 「メールを開く」リンクから該当メールへワンタップ移動

### 2. 状態の永続化（localStorage）
- 取り込んだメール本体・既読／スター／処理済み・サンプル表示設定を **ブラウザに保存**
- 再訪時に **前回の続きから自動復元**し、「💾 前回の続きから再開しました（取り込み◯件・処理済み◯件）」バナーで通知
- 外部サーバ不要・完全クライアント完結（GitHub Pages のまま動作）

### 3. 処理済み／未処理の管理
- メール詳細から「✓ 処理済みにする / ↩️ 未処理に戻す」を切替（ToDo 完了と連動）
- 処理済みメールは一覧で淡色＋取り消し線＋「✓ 処理済み」バッジ表示で **放置メールが減る実感**
- サイドバーに **「🎯 今日やること」「✅ 処理済み」** フィルターを追加（件数バッジ付き）

### 4. デモ用リセット
- 「🔄 すべてリセット」で保存データを消去し初期状態へ（他人に見せた後にまっさらに戻せる）
