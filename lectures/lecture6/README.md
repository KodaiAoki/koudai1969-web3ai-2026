# 第6回課題 — プロトタイプ v2

## プロダクト概要

**UniFilter AI v2** — 大学生向け AI メールフィルタリングダッシュボード（進化版）

## v1 からの進化ポイント

| 機能 | v1 | v2 |
|------|----|----|
| メール詳細表示 | ❌ | ✅ クリックで全文＋AI要約を表示 |
| AI 返信ドラフト | ❌ | ✅ ワンクリックで返信文を自動生成 |
| 新規メール作成 | アラートのみ | ✅ モーダル＋AI件名提案 |
| 締切タイムライン | ❌ | ✅ サイドバーにプログレスバー付きで表示 |
| キーボードショートカット | ❌ | ✅ J/K 移動・R 返信・E 既読・/ 検索 |
| トースト通知 | ❌ | ✅ 操作フィードバックを右下に表示 |
| メールデータ | 10件 | ✅ 9件（本文・AI要約・返信ドラフト付き） |
| v2 バッジ | ❌ | ✅ ヘッダーに表示 |

## 新機能の詳細

### 1. メール詳細パネル
メールをクリックすると右パネルが「ダイジェスト」から「メール詳細」に切り替わり、
送信者・件名・全文・AI要約・アクションボタンを表示。

### 2. AI 返信ドラフト生成
「AI で返信を作成」ボタンを押すと、文脈に合った返信文をモーダルで表示。
編集してそのまま送信できる。

### 3. 締切タイムライン
サイドバー内に残り時間をプログレスバーで可視化。
- 赤：24時間以内
- 黄：3日以内
- 緑：余裕あり

### 4. キーボードナビゲーション
| キー | 動作 |
|------|------|
| `J` | 次のメールへ |
| `K` | 前のメールへ |
| `R` | 選択中のメールに返信ドラフト |
| `E` | 既読にする |
| `/` | 検索欄にフォーカス |
| `Esc` | 閉じる |

## 技術スタック

- HTML / CSS / JavaScript（単一ファイル `index.html`）
- フレームワーク・ビルドツール不使用
- ダークテーマ UI、CSS Grid レイアウト

## ファイル

- `index.html` — 動作するプロトタイプ（ブラウザで直接開けます）
